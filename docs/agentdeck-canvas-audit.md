# 画布节点编排：审查与验收

范围：桌面版画布、普通 Agent 与 Workforce 的配置入口、创意工坊。对照版本为 3bc19d67。判断依据是现有产品规范、节点实际操作、代码和截图，不以扫描器代替界面验收。

## 修改前的审查

| 维度 | 评分（每项 4 分） | 依据 |
| --- | ---: | --- |
| 可访问性 | 2 | 表单已有标签和焦点，但即使能操作鼠标，也没有建立节点连接的入口。 |
| 性能 | 3 | 团队还没有任何任务时，详情页仍每 1.5 秒读取历史。 |
| 响应式布局 | 2 | 居中弹窗遮挡了当前节点和相邻节点，操作配置时无法看见上下游；长名称选择器缺少菜单宽度约束。 |
| 主题 | 4 | 已采用共用字段、图标和文字角色，浅色、深色沿用同一套语义。 |
| 实现与意图的一致性 | 1 | 节点可独立配置，但画布的边固定为空，团队的分支与汇总关系只能读。同名模板的不同版本在画布上看起来相同。 |
| **总计** | **12/20** | 技术评分，未做全产品或 WCAG 合规认证。 |

优先处理的问题（P0 两项，P1 两项，P2 两项）：

1. **P0，画布没有连线。** AgentCanvas 将 edges 设为空数组并关闭连接；无法用两个新建 Agent 构成可用路径。增加同 Session 的持久连线和不用拖拽的等效入口。
2. **P0，团队结构固定。** WorkforceDetails 只能编辑被指定的成员配置，无法改变由谁处理哪个分支或汇总。对所有团队实例提供同一组可保存的编排操作。
3. **P1，配置遮住工作对象。** 普通节点和团队都需要在保留画布方位的情况下编辑。复用产品的右栏宽度和表单，选中节点后同时看见图与配置。
4. **P1，版本和触发条件难辨。** 卡片没写版本；关键词接在模型名后面，读者无法判断含义。显示版本，条件用「消息包含…」表达。
5. **P2，工坊很难比较。** 全部模板藏在一个选择器里。改成可直接选择的名称和版本列表，同时保留派生关系。
6. **P2，无任务仍轮询。** 已完成或无任务时停止定时请求，本面板提交新消息时重新读取。

## 实现与实测

参考 [Dify 的分支、节点配置与汇总示例](https://docs.dify.ai/en/learn/tutorials/workflow-101/lesson-05)。AgentDeck 仍以 Session 隔离任务，区分两种连接：

- **手动转交（实线）**：右侧输出拖到接收节点左侧输入；或使用节点的连接按钮。选择上游任务和回答、下游任务、补充说明，确认后才运行。连线和断线都不改历史；相同来源、去向只保存一次。
- **团队执行（展开后以虚线显示）**：可替换、添加、删除分支，设置各分支条件和说明、改选汇总节点与规则；提交团队任务时按保存的配置执行。模板版本本身不被实例编辑覆盖。拒绝跨会话引用和递归包含，冲突编辑不会覆盖较新的版本。

在新建的「自由编排 · 试用」会话，从两个普通 Agent 拖出 A→B。重新载入桌面后仍能点击连线。A（Luna）答「青竹方案，预算 17 元。」；将这一次回答转交给 B（Sol），追加「只回答预算金额」，得到「17 元」。B 保存了当时引用的完整原文。点击节点名称即可进入右栏，在「对话」「通用」「能力」之间切换。

在同一会话从内置 Workforce 建立新实例，增删分支、指定 A 起草、B 条件审查、B 汇总，保存为「提案复核组」。发送含「审查」的预算题，两个分支均成功，产生一次汇总「5元」。画布切换节点后，连接端点、边和路由入口仍可见。该测试没有修改已有的预约团队。

复用 ContentHeader、右栏宽度、Tabs、Input、Select、Textarea、Button、DsText、DsIcon。没有新增设计规范例外。已检查选中、空闲、禁用、编辑、保存及完成状态；检查了明暗两种主题、780 × 650 桌面视口和键盘可达入口。没有做真机触屏、屏幕阅读器认证。Impeccable 4.4 的机械扫描返回空列表。完整截图和扫描原件保存在本地忽略目录 .agentdeck-run.local/ui-previews/impeccable-workforce/，不随代码发布。

## 2026-11-06：画布布局与视觉整理

本轮按用户选择聚焦画布布局、视觉样式，复用现有中性色、圆角和桌面控件。实查发现：标题行三个按钮抢占名称空间；试运行结果替换模型名；路由入口独占一行造成空白；居中结果弹窗遮住连线。用户当前窗口较窄，强制右栏也会把节点缩得难读。

修改后，会话边界以弱虚线标识，路由入口并入会话标题行。节点按名称、模型、结果摘要、状态/试运行分层；名称直接打开配置，次要操作放入“更多操作”，保持手动连接和转交。卡片高度由 100 调整到 120 个画布单位，宽度与已有坐标保留。移除显示用的路由留白，不迁移保存坐标或任务数据。

试运行输入和结果复用 NodeInspector。大窗口在右侧，小窗口在下方，极窄窗口覆盖当前工作区域；输入面板在小窗口给予更多高度。打开时自动定位本次路径，关闭不会触发运行。回答用现有 Markdown 组件，支持在同一面板切换 A、B、展开原始任务和当轮引用。节点配置与试运行面板互斥，Escape 关闭后恢复触发按钮焦点。缩放工具显示当前百分比。

验证使用本地「自由编排 · 试用」已有结果，没有重新向模型发送用户的任务。检查了明暗主题、当前窗口、1440 × 900 与 780 × 650 的布局；检查了模型名、结果查看、A/B 切换、手动转交入口、Escape 焦点恢复，以及打开配置后只有一个检查面板。截图保存在忽略目录 .agentdeck-run.local/ui-previews/canvas-polish/。未验证真机触屏、屏幕阅读器和系统 200% 缩放。

复用 Button（xs/sm，text/ghost/secondary）、DropdownMenu、Badge（语义状态色）、Textarea、DsText、DsIcon、MarkDown、NodeInspector 和共用自适应栏宽。采用 Neutral、Hairline、Ink 与 Success/Error/Information 语义；未新增设计规范例外，画布几何继续使用既有第三方视口规则。

验证：type-check、check:design-tokens、focused ESLint、17 项相关 Vitest、git diff --check。Impeccable 检测无机械违规。


## 2026-11-06：工作区统一画布

统一入口复用既有 Space/Session、任务、trigger、memory 的原始 ID。会话使用容器区域，Agent 使用双框卡牌结构，其他对象使用紧凑资源节点。任务和团队内部节点按需展开，减少默认画布密度；资源默认放在执行节点左侧，连线沿读取与执行方向进入节点。画布与目录编辑的是同一记录，原会话入口、试运行、断开连线和手动转交仍可用。

复用 ContentHeader、NodeInspector、AgentForm、CanvasNodeTasks、CanvasTrials、WorkforceDetails、TaskRouter、Button（text/ghost/secondary）、Tabs、Input、Select、Checkbox、Textarea、DsText、DsIcon。继续使用 Neutral/Ink/Hairline/Accent 与状态语义色、ds-card/panel/field 圆角和共用栏宽。卡牌装饰为几何线条，没有引入新字体、原始颜色或设计例外。

检查了加载、错误反馈、资源编辑/引用保存、选中、执行状态、删除后引用解除、明暗主题，1440×900 与 780×650 桌面视口。窄窗口沿用底部检查面板，打开节点时自动定位所选卡牌；未做真机触屏、屏幕阅读器认证。布局、折叠状态和视口恢复经桌面重开验证。源文件机械扫描无发现（Impeccable detect 返回 []）。截图在本地忽略目录 .agentdeck-run.local/ui-previews/workspace-graph/。

功能验收使用独立测试会话，不改写已有用户对话。真实模型确认选择的资料/记忆进入执行；修改资料保留历史版本；两次手动自动化生成独立会话，重复投递没有额外运行。自动化验收样本保持 inactive，无天气定时或外部通知。

验证通过：88 项相关 Vitest、34 项后端 pytest、type-check、focused ESLint、check:design-tokens、check:i18n、git diff --check。pytest 报告仓库既有 asyncio fixture 弃用警告。最终定向代码复审通过。


## 2026-11-06：资源连线命中与保存修复

用户报告 Context/记忆/自动化拖到 Agent 不能连接。桌面复现表明：精确命中时请求成功，但在“适应全部会话”的缩放下，原生端口只有约 2.1 屏幕像素；偏离中心 5 像素不能启动连线。资源节点还暴露了规则不接受的输入端口。另复现页面引用版本落后时的 409 保存失败。

端口沿用 React Flow Handle，保持卡牌和连线的中心锚点。命中区域使用 controlHeight-xs（24px）并抵消画布缩放，粗指针使用既有 touch-target-minimum。保留 Ink/Hairline/Accent 语义，复用 DS_FOCUS_RING；悬停、有效目标和键盘焦点有反馈。资源仅显示输出端口；会话/任务的归属锚点只显示关系，不接受交互。可拖拽、依次点击，或聚焦端口按 Enter/空格连接。画布加入简短方向说明。使用既有 third-party-viewports 几何例外，无新增颜色或标准控件例外。

资源连接按画布依次保存，每次读取服务端当前引用/绑定版本，再追加目标资源；成功后立即更新本地连线，不依赖整个目录刷新结束。保存失败不会堵住之后的操作。

验证：4 个端口行为测试先失败后通过，连同引用并发、模型投影和编辑器测试共 11 项通过；type-check、focused ESLint、check:design-tokens、check:i18n、git diff --check 通过，Impeccable 扫描无发现。真实桌面以中心偏移 5px 拖入 Context、点击连接记忆、键盘连接自动化；故意保留旧界面版本后连续三条连接均返回 200，刷新后恢复全部三条关系，原验收引用已恢复，未执行模型任务。检查明暗主题、24px 屏幕命中区域；未做真机触屏验证。截图保存在本地忽略目录的 workspace-graph/ports-*.png。
