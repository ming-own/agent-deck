# Contributing to AgentDeck

AgentDeck（智牌）is developed and maintained by ming-own.

Use <https://github.com/ming-own/agent-deck> for issues and pull requests. Do not
submit this project's changes to the original Eigent repository.

1. Read [AGENTS.md](AGENTS.md) and the relevant design and terminology guidelines.
2. Keep changes focused on the maintainer's requested behavior.
3. Preserve existing APIs and data formats unless a migration is explicitly planned.
4. Run the checks appropriate to the changed files, including `npm run type-check`,
   focused tests, and `git diff --check`. Run `npm run check:i18n` for locale edits.
5. Preserve original copyright notices and license terms.

See [maintenance notes](docs/agentdeck-maintenance.md) for release settings and
compatibility boundaries inherited from Eigent.
